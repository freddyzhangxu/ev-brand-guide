# EV design system checklist

## P0 — must pass

- EV Black, EV White, and EV Red are the dominant brand colors.
- Purple is used only in the EV red-purple gradient, not as a standalone accent.
- Text is left-aligned and uses confident, concise EV voice.
- Headlines use the EV display posture: bold, condensed, direct.
- No lorem ipsum, fake metrics, generic feature labels, or emoji icon rows.
- Product/audio context is specific: loudspeaker, microphone, sound coverage, installation, rental, performance, dealer, or support modules.
- Responsive web output has meaningful desktop, tablet, and mobile layouts.
- iOS screens use iOS-safe layout and 44px minimum hit targets.
- Android screens use Android-safe layout and 48dp minimum hit targets.
- Distinct user-facing screens are separate HTML files unless the user explicitly asks for one single-page artifact.

## P1 — should pass

- Web components align to a 4px grid.
- Buttons use EV sizing: 48px large, 32px medium, 24px small.
- Logo clear space is preserved when logo assets are included.
- Real product images are used when provided; otherwise labelled placeholders are honest and minimal.
- Status colors follow the EV guide: yellow for notices, green for positive feedback, red for errors.
- Sales/marketing modules include concrete actions such as compare, configure, download, request demo, dealer/contact, or support.

## P2 — polish

- One decisive red accent moment anchors each major screen.
- High-contrast black/white layouts feel premium and professional, not generic dark mode.
- The final artifact avoids beige, peach, generic violet, and decorative pastel AI-style backgrounds.
- PPT-style outputs use the black footer variant unless the user overrides it.
