# Example brief

Create an EV-branded responsive product launch experience for a new professional loudspeaker series.

Audience: sales team, dealers, installers, and product managers.

Platforms:

- Desktop web product page
- Responsive mobile web
- iOS sales companion screen
- Android sales companion screen

Must include:

- Product hero with EV Black/White foundation and a single EV Red accent moment
- Sound coverage or system configuration module
- Product comparison module
- Download/spec sheet action
- Dealer/contact CTA
- Platform-specific mobile navigation and hit targets

Avoid:

- Generic purple gradients
- Beige or peach backgrounds
- Emoji icons
- Fake performance metrics
- Purple as a standalone accent
