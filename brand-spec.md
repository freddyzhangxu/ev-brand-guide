## Layout posture

- Lead with black, white, and EV Red; use Purple only in the official red-purple gradient, not as a standalone decorative accent.
- Keep text left-aligned; headlines should be bold, condensed, concise, and confident.
- Use vivid real environments, product close-ups, or 3D product renderings; avoid generic abstract illustrations.
- Build structure with boxes, split vertical/horizontal layouts, full-picture layouts, and grid-aligned web banners.
- Align web banner components to a 4px grid; use clear button heights: 48px large, 32px medium, 24px small.
- For EV PPT outputs, default to the black footer variant with KEENFINITY as text only.

## Voice

Concise, confident, conversational. Avoid empty claims; focus on sound quality, engineering, reliability, flexibility, and real customer outcomes.
